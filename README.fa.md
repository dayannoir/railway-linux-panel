# Railway Linux Panel

پنل مدیریتی سبک و امن برای اجرای سایت، API و بات داخل همان Container در Railway.

## ورود پیش‌فرض

- نام کاربری: `admin`
- رمز عبور: `admin`

در اولین ورود، از بخش تنظیمات فوراً نام کاربری و رمز را تغییر بده. پنل تا قبل از تغییر اطلاعات، اجرای ترمینال و برنامه‌ها را مسدود می‌کند.

## راه‌اندازی

1. محتوای این پروژه را داخل GitHub بگذار.
2. در Railway از GitHub Repo یک سرویس بساز.
3. یک Railway Volume بساز و آن را روی مسیر زیر Mount کن:

```text
/data
```

4. از تب Networking یک Domain بساز.
5. با آدرس Domain وارد پنل شو.

## امکانات

- داشبورد وضعیت
- File Manager روی `/data`
- آپلود و ویرایش فایل‌های متنی
- اجرای سایت و بات با Process Manager
- لاگ برنامه‌ها
- ترمینال محدودشده
- تغییر نام کاربری و رمز
- Node.js، Python، Git، FFmpeg و SQLite

## ساخت برنامه

از بخش «برنامه‌ها و بات‌ها» نام، مسیر و دستور اجرا را وارد کن. نمونه:

```text
نام: my-bot
مسیر: apps/my-bot
دستور: python3 bot.py
```

اطلاعات حساس مثل توکن بات را در فایل یا GitHub نگذار؛ برای نسخه‌ی اول آن را داخل تنظیمات برنامه نگذار و فقط از Railway Variables یا فایل خصوصی روی Volume استفاده کن.

## نکات امنیتی

این پنل cPanel کامل یا VPS نیست و فقط همان Container را مدیریت می‌کند. ترمینال عمداً دستورات خطرناک، مسیرهای خارج از `/data`، دسترسی Docker و ابزارهای شبکه‌ی تهاجمی را مسدود می‌کند. رمز پیش‌فرض را حتماً بعد از ورود تغییر بده و Domain پنل را عمومی و بدون احراز هویت رها نکن.
